# yIsobath

[English](README.md) · 简体中文 · [日本語](README.ja.md)

一个放在桌面上的磁盘测量仪器。测整块数据卷、个人文件夹或任意文件夹，把它画成一座阶梯浮雕：
每一层文件夹一级台阶，每个字节一段弧，可以按文件类型、年龄和可回收空间来读。看到想清理的东西，
可以在访达中显示，或者移到废纸篓。

## 下载

在 [Releases](https://github.com/maosensen/yIsobath/releases/latest) 下载：

- macOS：`.dmg`，Apple 芯片选 `aarch64`，Intel 选 `x64`。已用 Developer ID 签名，并经过 Apple 公证。
- Windows：`.msi` 或 `-setup.exe`。还没有代码签名，第一次安装时 SmartScreen 会提示。
- Linux：`.deb`、`.rpm` 或 `.AppImage`。

装好之后，每次启动会检查一次更新。

## 它读什么，从不做什么

- 只读**名称、实际占用和修改时间**，从不打开文件内容。任何东西都不会离开这台电脑。
- 每个测过的地方留**一份快照**，只有文件夹的名字和大小，存在应用自己的数据文件夹里。
  下次测同一个地方时，用它告诉你这段时间哪里变大了。
- 大小按**实际分配的块**计算，与 `du` 一致：稀疏的磁盘映像按真实占用算，被 iCloud 移走的文件不占空间，
  有多个硬链接的文件只算一次。
- 测整块磁盘时走的是**数据卷**（macOS 上的 `/System/Volumes/Data`），只测这一块卷；别的设备会被跳过并计数。
- macOS 不让列出的文件夹**计为无法读取**，不会悄悄漏掉。想测全部内容，请在系统设置里给它“完全磁盘访问权限”。
- **只移到废纸篓，从不删除**。每次移动前都先确认；测量的根、系统文件夹、账户文件夹（`~/Library`、`~/Documents`……）
  和已经在废纸篓里的东西一律拒绝。
