# yIsobath

[English](README.md) · [简体中文](README.zh-CN.md) · 日本語

デスクトップで使うディスクの測量計器です。データボリューム全体、ホームフォルダ、または任意のフォルダを測量し、
段々のレリーフとして描きます。フォルダの階層ごとに1段、容量に応じた弧で、ファイルの種類・経過・回収できる容量の
3つの見方で読めます。片付けたいものが見つかったら、Finder に表示するか、ゴミ箱に入れられます。

## ダウンロード

[Releases](https://github.com/maosensen/yIsobath/releases/latest) からどうぞ。

- macOS：`.dmg`。Apple シリコンは `aarch64`、Intel は `x64`。Developer ID で署名し、Apple の公証を受けています。
- Windows：`.msi` または `-setup.exe`。まだコード署名していないため、初回インストール時に SmartScreen の警告が出ます。
- Linux：`.deb`、`.rpm`、`.AppImage`。

インストール後は、起動するたびにアップデートを確認します。

## 読むもの、決してしないこと

- 読むのは**名前・実際の使用量・更新日時**だけで、ファイルの中身は開きません。このコンピュータの外には何も送りません。
- 測量した場所ごとに**スナップショットを1つ**残します。中身はフォルダの名前とサイズだけで、アプリのデータフォルダに
  保存します。次に同じ場所を測量したとき、その間にどこが増えたかを示すのに使います。
- サイズは `du` と同じく**実際に割り当てられたブロック**で数えます。スパースなディスクイメージは実際の使用量で、
  iCloud に退避したファイルはゼロで、複数のハードリンクがあるファイルは1回だけ数えます。
- ディスク全体の測量では**データボリューム**（macOS では `/System/Volumes/Data`）を走査し、ほかのデバイスには
  移りません。ほかのデバイスはスキップして件数を表示します。
- macOS が一覧を許さないフォルダは**読めないフォルダとして数え**、黙って落としません。すべてを測量するには、
  システム設定でフルディスクアクセスを許可してください。
- **ゴミ箱に入れるだけで、削除はしません**。移動の前に必ず確認し、測量のルート、システムのフォルダ、アカウントの
  フォルダ（`~/Library`、`~/Documents` など）、すでにゴミ箱にあるものは受け付けません。
