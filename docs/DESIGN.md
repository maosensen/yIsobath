# yIsobath — 设计

一台测量磁盘的桌面仪器。把一块数据卷、家目录或任意文件夹画成往外逐级下降的阶梯浮雕:每一层目录一圈台阶,
张角就是字节;旁边是焦点读数、可回收空间、年龄地层与查找。看到想清理的东西,可以在访达中显示,或者移到废纸篓。

## 来历

仪器本体来自 yLookbook 的 `sections/isobath`(2026-09-27)。那一版是一个 section:演示卷是生成的测量记录,
浏览器里最多能测一个自己选的文件夹,读不到整块盘、读不到物理占用、删不了文件 —— 它自己的 DESIGN.md 里
「已知边界」那一节几乎全是浏览器沙箱造成的。用户问「能不能真的落地成一个 Tauri 应用,一边做一边在自己电脑上用,
像 yAssets 一样」,于是有了这个仓库:外壳从 yDesktopTemplate v0.2.0 起步,仪器整体搬过来,测量换成 Rust。

搬过来之后**这里是上游**,lookbook 那份保持演示卷不再同步。

## 浏览器版 → 桌面版

| | yLookbook(浏览器) | yIsobath(桌面) |
|---|---|---|
| 能测什么 | 用户挑的一个文件夹 | 整块数据卷、家目录、任意文件夹 |
| 怎么走 | `showDirectoryPicker` 逐个 `getFile()`,或 `webkitdirectory` 一次交清单 | Rust `rayon` 并行 `read_dir` + lstat |
| 大小 | 逻辑长度 | 实际分配的块(`blocks × 512`),和 `du` 一致 |
| 硬链接 | 每份都算 | 按 `(dev, ino)` 只算一次 |
| 稀疏文件 | Docker.raw 按逻辑长度,规则里按 70% 估回收 | 按实际占用;规则里的 70% 回收比例保留(它估的是「其中多少是没用的层」) |
| 别的卷 | — | 只测一块卷,别的设备跳过并计数 |
| 读不到的目录 | — | 计数,测完显示「N unreadable」,没有权限时给打开系统设置的入口 |
| 上限 | 150 万个文件 | 没有文件数上限;发给界面的节点按预算折叠(见下) |
| 删除 | 只给出命令 | 移到废纸篓(确认 + 守护名单) |
| 卷容量 | 读不到 | `statfs`:容量与剩余空间 |

## 测量

- **只读元数据。** 名字、占用、修改时间。不打开文件,不跟随符号链接,什么都不发出去。
- **整块盘 = 数据卷。** macOS 上用户的东西都在 `/System/Volumes/Data`,经 firmlink 出现在 `/Users`、`/Applications`……
  从 `/` 走要么因为跨设备被跳过、要么重复计数,所以「整块盘」走数据卷本身,卷名从 `/Volumes` 里指向 `/` 的那个符号链接读
  (「Macintosh HD」)。界面上的路径照 firmlink 的样子写(`/Users/…`、家目录写 `~`);复制出去的路径也是这一种。
- **权限。** 没有完全磁盘访问权限时,读 Desktop / Documents / Downloads 会弹系统授权,别的 app 的数据目录直接拒绝。
  测整块盘或家目录之前先说清楚;权限检测是试着打开系统的 TCC.db —— 只有有权限时打得开,而且不会弹窗。
- **折叠。** 完整的树留在 Rust 内存里(`Survey`),界面拿到的是折叠后的:
  - 不小于阈值 T 的目录展开;
  - 更小的目录折成一块(名字、总量、规则记号都在,是真路径,能显示、能移到废纸篓,进不去),条件是它至少有 T/16,
    或者带规则记号且至少 100 kB;再小的并进所在目录的「N files」;
  - 一个小目录里如果有至少 max(T/16, 100 kB) 落在带记号的地方(一个小项目的 node_modules),它照样展开,
    不然规则就看不见那块 node_modules;
  - 不小于 max(1 MB, T) 的文件单独成节点;
  - T 从 max(1 MB, 总量 / 10⁶) 起倍增,直到不超过 6 万个节点。字节在折叠前后守恒(有单测)。
- **年龄。** 每个叶子带修改时间;折叠的块与「N files」用按字节加权的平均年龄。目录的中位年龄从按季度的直方图插值,
  插值两头收到子树里真实的最新 / 最老时间 —— 原版一个全是今天文件的目录会显示「7 周」(半个季度)。

## 规则与记号

规则沿用 lookbook 的 14 条(风险三档、清理命令、回收比例),定义在 `src/instrument/catalog.ts`。Rust 按名字打记号
(`classify.rs`),记号字符串就是规则匹配的那个:

- 来自浏览器版:`node_modules`(嵌套的不重复算)、`DerivedData`、`.next` / `.turbo` 等、`dist` / `out` / `build`
  (旁边得有 `src`)、`target`(旁边得有 `Cargo.toml`)、各家缓存、`Logs` / `DiagnosticReports`、`.Trash`;
- 原生新增:卷的 `.Trashes`;`~/Library/pnpm/store`、`~/.cargo/registry`、`~/.gradle/caches`、`~/.bun/install/cache`;
  Xcode 的 `UserData/Previews`;一年以上没动过的 `* DeviceSupport/<版本>`;`Docker.raw`;
- 安装包(`.dmg` / `.pkg` / `.iso` / `.xip` / `.msi`)只认 Downloads 和 Desktop 里的 —— app 包里或缓存里的同类文件不是剩下的;
- 「重复」仍是同名同大小、50 MB 以上,没读内容,所以只能说「很可能」;
- 「退役运行时上的模拟器」这条规则在原生测量里不会命中:要读 `simctl` 的设备清单才知道哪些运行时退役了,第一版没做。

## 操作

- **在访达中显示 / 复制路径 / 移到废纸篓**:焦点面板的操作条(作用于选中的那块,没选中就是焦点)、浮雕上右键、⌘⌫。
  「N files」那一块没有自己的路径,操作落到它所在的目录。
- **移到废纸篓**先弹确认:路径、大小、文件数、命中的规则与风险,一句「清空废纸篓才拿回空间」,默认焦点在「取消」。
  Rust 再查一遍:必须在当前测量里、不是测量的根、不在守护名单里(`/`、`/System`、`/usr`、`/Library`、`/Applications`、
  `/Users`、`~`、`~/Library`、`~/Documents`、`~/Desktop`、`~/Downloads`、`~/Pictures`……)、不在废纸篓里。
  macOS 用 NSFileManager(不需要「控制访达」的自动化授权,访达没开也行)。
- 移走之后在内存里的树上摘掉这一块;如果测量范围包含 `~/.Trash`,把它挂到废纸篓下面 —— 空间没有真的腾出来,画面不撒谎。
  然后按原来的阈值重新折叠、整块换掉,焦点和视角按名字链找回来,不跳。

## 为桌面版改的界面

- 窗口不透明,底色就是仪器的底色;红绿灯放在顶栏正中的高度,顶栏左边让出位置,整条顶栏可以拖动窗口、双击缩放。
- 测量入口收成一个「Survey…」菜单(整块盘 / 家目录 / 选文件夹 / 回到演示卷);状态区测完显示「Survey again」。
- 顶栏的卷标签:文件夹不在家目录下时只留最后两段(`…/scratchpad/trash-test`),整条路径在悬停提示里。
- WebKit 修正:分段条不再用浮动的 `<legend>`(WebKit 不让它和按钮排在同一行)。
- 原版就有、在这里修掉的:左侧引线标签名字短、数字长时,数字那行钻到左栏下面;轮毂第二行太长时从中间截断(现在只留文件数);
  文件夹测量的读数写「of volume」(现在写「of survey」);悬停标注对折叠的块不显示文件数。

## 发明清单(相对 lookbook 版新增的判断)

1. 「整块盘」= 数据卷,路径按 firmlink 写。
2. 占用按分配块、硬链接只算一次、只测一块卷。
3. 折叠规则:T 的起点与倍增、T/16 与 100 kB 两条线、为可回收内容展开的小目录、6 万个节点的预算。
4. 折叠块与「N files」的年龄用字节加权平均;中位年龄插值收边。
5. 原生新增的记号与「安装包只认 Downloads / Desktop」。
6. 守护名单与「已在废纸篓里的不再移」。
7. 移到废纸篓后把字节挂到 `~/.Trash` 下。
8. 走盘线程数 = 核数 × 2(8–32);进度 120 ms 一次。

## 已知边界

- 折叠的目录进不去(要钻进去得重新测那个文件夹);下一步是按需展开(完整的树已经在 Rust 那边)。
- APFS 克隆共享的块会按两份算;可清除空间(purgeable)、本地快照不在任何文件夹里,所以测出来的总量小于「已用」,
  界面还没把这个差额标出来。
- 「重复」只比同名同大小;退役模拟器那条规则不命中;清理命令只能复制,不代跑。
- 读 iCloud / File Provider 的目录时,系统可能要向提供方要目录清单,会慢。
- dev 构建(`pnpm tauri dev`)不是 Developer ID 签名,完全磁盘访问权限要单独给;只有签名稳定的正式版,权限才跨更新保留。
- 没有快照和两次测量的对比。

## 性能(本机实测,2026-10-01)

- 走盘:`~/github` 174 万个文件、20 万个目录、160 GB,release 13.0 s、debug 14.5 s;yLookbook(16.5 万文件)0.98 s;
  总量与 `du -sk` 逐字节一致(14.864 GB / 34.985 GB 两个样本)。
- 折叠:3.8 万个节点、4.2 MB JSON,折叠 14 ms。
- 画面:WKWebView 里 WebGL2 是 Apple GPU、浮点缓冲、4× MSAA;2880 × 1776 的缓冲、1186 个可见扇区,
  回放与测完都是 60 fps(帧时间 16–18 ms)。
